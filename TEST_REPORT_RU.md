# Отчёт о проверке проекта

Дата проверки: 2026-10-29

## Проверки, выполненные локально

- Все JSON-ресурсы разбираются встроенным парсером Python.
- В проекте присутствуют ровно 12 файлов определений измерений.
- Каждый файл измерения содержит генератор и источник биомов.
- Все 12 идентификаторов измерений имеют соответствующую команду перехода в Java-исходнике.
- `fabric.mod.json` содержит идентификатор мода и основной entrypoint.

Запуск проверок:

```bash
python tools/test_project.py
```

## Что пока не удалось проверить

Полная сборка Gradle и запуск Minecraft не выполнялись: в текущем окружении установлена Java 21, тогда как проект настроен на Java 25, и команда `gradle` отсутствует. Также для настоящего runtime-теста нужны скачанные зависимости Minecraft/Fabric. Следовательно, успешные структурные проверки не означают, что мод уже компилируется или загружается в игре.

## Ограничение текущего прототипа

Сейчас 12 измерений имеют разные идентификаторы, но используют комбинации ванильных генераторов Overworld, Nether и End. Это каркас для дальнейшей разработки, а не 12 законченных уникальных измерений. Уникальные биомы, блоки руд, предметы-артефакты, лаборатории/бункеры и финальный босс ещё требуют реализации.


## Портирование на Minecraft 1.21.1
- Версии проекта переключены на Minecraft 1.21.1, Java 21, Fabric Loader 0.16.14 и Fabric API 0.116.1+1.21.1.
- Фактическая Gradle-сборка не выполнена: в рабочей среде нет Gradle и нет сетевого доступа к репозиториям зависимостей. Поэтому совместимость на уровне запуска игры пока не подтверждена.
