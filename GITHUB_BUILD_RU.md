# Облачная сборка мода через GitHub Actions

## Как запустить сборку

1. Создай **Private repository** на https://github.com/new.
2. Назови его `razlomy-izmereniy` и создай репозиторий.
3. На странице репозитория выбери **Add file → Upload files**.
4. Распакуй ZIP проекта на компьютере и перетащи **все файлы и папки внутри** распакованной папки в окно загрузки GitHub. В том числе должны загрузиться `build.gradle`, `settings.gradle`, `gradle.properties`, `src`, `tools` и скрытая папка `.github` с workflow.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** в репозитории. Выбери workflow **Build Minecraft mod** и нажми **Run workflow**, если сборка не запустилась автоматически после загрузки.
7. Открой последний запуск. Если он завершился зелёной галочкой, прокрути страницу вниз до **Artifacts** и скачай `razlomy-izmereniy-minecraft-1.21.1`.
8. Распакуй скачанный artifact ZIP. Внутри будет JAR-файл. Для Minecraft 1.21.1 также нужен Fabric Loader и Fabric API соответствующей версии.

## Если сборка упала

Открой запуск в Actions, нажми на шаг **Build mod**, скопируй последние 30–50 строк ошибки и передай их в ChatGPT. Не публикуй пароли, токены или секреты.

> Workflow собирает проект, но успешная компиляция сама по себе не гарантирует, что все игровые механики мода полностью реализованы или проверены в запущенном Minecraft.
