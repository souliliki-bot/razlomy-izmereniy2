# Разломы измерений — прототип Fabric

В архиве находится исходный проект и дизайн-план 12 измерений с финальной зоной. Основная прогрессия описана в `DESIGN_RU.md`.

## Целевая кампания
- 12 измерений, каждое со своей рудой, данжем, испытанием и артефактом-ключом.
- 12 ключевых артефактов открывают Особый разлом.
- Финальное измерение «Нулевая Грань» и босс «Архитектор Нуля» с тремя фазами.
- Лаборатории и бункеры в обычном мире служат точками обнаружения и активации разломов.

## Важно
Это дизайн-план, а не завершённый релиз. Не все измерения, артефакты, структуры и босс реализованы в Java-коде. Перед использованием в настоящем мире сделай резервную копию. Сборку и запуск в Minecraft необходимо проверить на целевой версии Fabric.


## Совместимость и сборка для Minecraft 1.21.1

Проект настроен под Minecraft Java Edition 1.21.1, Java 21, Fabric Loader 0.16.14 и Fabric API 0.116.1+1.21.1.

Чтобы собрать JAR на компьютере с интернетом и установленным JDK 21 и Gradle 8.10.2+:

1. Распакуй архив.
2. Открой терминал в папке проекта.
3. Выполни `gradle build`.
4. Готовый файл появится в `build/libs/razlomy-izmereniy-1.0.0.jar`.
5. Установи Fabric Loader для Minecraft 1.21.1, положи JAR и Fabric API в папку `mods`.

Важно: в этой среде сборку Gradle не удалось выполнить, потому что Gradle не установлен, а доступ к Maven-репозиториям отсутствует. Архив содержит исходники, а не проверенный JAR. Измерения пока являются прототипами на основе стандартной генерации; уникальные блоки, артефакты, структуры и босс ещё не реализованы.
