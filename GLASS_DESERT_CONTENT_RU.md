# Стеклянная пустыня — план контента

Этот документ фиксирует первую группу контента для измерения. Реализация ведётся отдельно от основной ветки.

## Пять уникальных существ

| ID | Название | Роль | Уникальный дроп |
|---|---|---|---|
| sand_hunter | Песчаный охотник | Обычный быстрый хищник | Сырое мясо песчаного охотника |
| solar_scorpion | Солнечный скорпион | Обычный ядовитый моб ближнего боя | Солнечное жало и мясо скорпиона |
| glass_wanderer | Стеклянный странник | Обычный медленный бронированный моб | Стеклянная плоть |
| golden_sand_golem | Золотой песчаный голем | Редкий тяжёлый защитник | Золотое ядро |
| sun_eater | Пожиратель солнца | Мини-босс | Сердце солнца |

## Еда

Уникальные продукты выпадают только с соответствующих существ. Для каждого продукта будут заданы свойства насыщения и возможность приготовления, если это уместно. Боссовый дроп не должен быть обычным источником еды.

## Руда измерения

**Солнечная руда** — отдельный ресурс Стеклянной пустыни. Планируемые предметы:
- солнечный слиток после переплавки;
- солнечный сплав для рецептов брони и инструментов;
- солнечная пластина для усиленного снаряжения.

## Критерии готовности первой группы

- [ ] Зарегистрированы все пять типов существ.
- [ ] Существа имеют атрибуты, поведение и правила появления в Стеклянной пустыне.
- [ ] Для каждого существа есть таблица добычи с уникальным дропом.
- [ ] Добавлены предметы еды и солнечная руда.
- [ ] Добавлены модели, текстуры, имена на русском языке и клиентские рендереры.

## Техническое правило

Не считать моба готовым только по регистрации EntityType: необходимы серверная логика, спавн, loot table и клиентский renderer. Не переносить незавершённую реализацию в основную ветку.
